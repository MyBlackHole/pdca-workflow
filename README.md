## 开始

在本源码目录执行 `./setup --apply`，默认安装到 `~/.agents/pdca/`，在 `~/.agents/skills/` 注册八个入口。不创建业务项目 `.pdca/`，不触发任务、阶段或 Agent。首次使用项目时，仅在集中 records 中登记。

`pdca` 定位任务；`pdca-plan`、`pdca-do`、`pdca-check`、`pdca-act` 操作原任务；三个本体场景入口明确各自交付。Skill 是方法，不是执行者。每个场景内均是完整 PDCA，阶段之间只由匹配的用户操作推进。

集中根保存规则、本体、任务、确认、证据与跨项目资源预约；业务项目只接收明确授权的产品变更。任务上下文和记录写域各自独立，父 Agent 不监工、不代签、不接管。

## 本轮纠正

恢复 rc.1 被改变的集中式管理；恢复资源预约与操作记录；拆分 1+4+3 入口；加入有所属边界的安装、检查、卸载和项目登记。安装是文件操作工具，不是 PDCA Runtime；资源账本不是沙箱或锁。

`legacy` 不参与安装或运行。未采用的历史指针与参考知识不是当前控制规则；本包不恢复用户已删除的历史目录。真实能力未跑仍为 NOT_RUN，不以静态测试替代。
