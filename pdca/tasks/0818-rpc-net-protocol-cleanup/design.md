# 设计：移除 rpc-net-protocol 遗留实现

## 现状确认

旧实现只有自身定义和 `libs/rpc-net.c` 的 include；转换函数没有仓库内调用者。现行 RPC 时间消息由 C++ 协议模块实现，rdbcomm/RPC 新协议时间操作由握手模块实现。

## 修改边界

1. 删除旧 C 源文件和头文件。
2. 删除 `libs/rpc-net.c` 的无效 include。
3. 从 `libs/xmake.lua` 的 `rpc-net` target 移除旧源文件。
4. 用引用扫描、构建和完整测试验证行为保持不变。

## 风险控制

仓库内不再存在旧符号引用；若构建或集成测试失败，立即停止删除结论，检查是否有遗漏的内部依赖。外部 ABI 风险在 PRD 中明确为范围外，不伪造兼容保证。
