# PRD — 门禁误伤抽样与分层固化

> 任务：T0536 / 0902-fidelity-gate-calibration / scenario: development / phase: plan
> 跟进：T0535 建议1+2，1.5h轻量

## 背景

T0535以触发率（G6 30%、G7-G10 56%）判定“统计层过度”，但未度量L3的**有效误报率**（开发者未正向行动即误报），且四档处置未固化为本体契约，存在回退风险。

## 目标

补“有效误报率”实证，并将“门禁分层”固化为本体契约。

## 验收标准

### 验收标准
- [ ] AC-1 抽样量化：对G6的124泛化随机抽样20例，每例人工判定“真泛化/有效误报”，计算有效误报率并与L3 10%阈值对比，给出G6是否需再降级的结论
- [ ] AC-2 分层固化：在 `ontology:concept/ontology-fidelity-criterion.md` 增补“门禁分层”小节，明确G1-G5硬阻断/G6双条件+豁免/G7-G10统计不阻断三层，且 `ontology-validate` 与 `audit` 行为与文档一致
- [ ] AC-3 可复现：抽样表含抽样方法（随机种子）与判定标准，存于 `records/T0536-*/sampling.md`，可重跑

## 约束

- 抽样仅20例，判定标准沿用L3“未正向行动即误报”。
- 固化不改门禁行为，仅文档化现状（防回退）。
