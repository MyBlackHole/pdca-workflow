# btree搜索读路径专题学习

## 背景
评估后新方式第一轮：深挖 + 学习报告 + 指南导航，不再逐机制建节点。

## 目标
产出 btree 搜索读路径学习报告（对话全文 + 文件）+ 指南导航节点。

## 功能需求
1. 精读 iter.c 搜索路径、bset 查找、预取机制
2. 对话全文输出学习报告，并写报告文件，每节 file:line 锚点
3. 新建搜索指南节点，聚合搜索相关节点
4. 三查 + validate 全绿

## 非功能需求
- 只读分析；真实时间戳

## 验收标准
- [ ] AC-1 报告覆盖迭代归并/节点内查找/预取且有代码锚点，每节有设计启示
- [ ] AC-2 报告文件存在且对话输出与文件一致
- [ ] AC-3 新建指南导航节点并过三查与validate，conclusion含##本体沉淀

## 风险与对策
- 风险：与已有搜索节点重复。对策：指南导航不重复机制，只做路径聚合
