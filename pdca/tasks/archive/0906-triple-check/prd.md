# 本体三查强制门禁

## 背景
用户要求：产生的本体必须自查三次是否完整与详尽。落为强制门禁。

## 目标
定义三查内容并实现检查脚本，集成到本体入库门禁。

## 功能需求
1. 三查定义（完整性五要素导向）：一查结构（frontmatter/attributes/relations/体裁）；二查详尽（背景问题/核心机制带依据/适用边界/违反后果/关联导航五要素实质存在）；三查交叉（validate/引用存在/无重复）
2. 实现 scripts/check-ontology-thoroughness.py（机检结构存在性+依据标记+信号泛化词）
3. skill-ontology-check 增补三查步骤（含人工实质把关说明）
4. 回归验证通过

## 非功能需求
- 真实时间戳；改动可 diff 审计

## 验收标准
- [ ] AC-1 三查内容定义明确可执行（写入skill）
- [ ] AC-2 检查脚本实现并对新节点可运行
- [ ] AC-3 全量回归验证通过（含故意不合格fixture被拒）

### 声明的测试接缝
- seam: scripts/check-ontology-thoroughness.py -> ontology/新增节点（三查）

## 风险与对策
- 风险：误杀历史合格节点。对策：只卡新转换，不重跑历史
