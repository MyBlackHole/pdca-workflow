# T0140 执行计划

1. 为五个项目各采集至少两个官方来源，登记 source inventory。
2. 复跑本地 PDCA 的 doctor、15 个状态/操作测试、12 个场景 fixture 和归档审计。
3. 按七维度生成带 source ID 的 comparison matrix。
4. 编写逐项目优劣和本地横向分析。
5. 生成候选建议并逐项执行价值淘汰：
   - 有明确消费者；
   - 可指向准确度、效率、恢复或安全收益；
   - 有本地验证方法；
   - 有失败即删除的条件。
6. 校验来源数量、引用完整性、JSON/JSONL 和报告边界。

不安装外部框架、不调用付费模型、不修改本地 PDCA 实现。
