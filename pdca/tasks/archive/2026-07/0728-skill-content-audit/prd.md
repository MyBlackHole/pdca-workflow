# 量化审查 skill 内容量并精简 Pareto 候选

## 问题陈述

T0130 主要按行数和引用次数压缩，尚未验证稳定内容成本、重复度、导航结构和任务效果。继续以“越短越好”为目标可能删除必要的失败处理或适用边界。

## 解决方案

- 使用零模型依赖的 UTF-8 bytes；模型真实 token 留给未来 Agent runner。
- 自动计算结构、规范化重复和引用图；单独使用 rubric 审查信息密度、渐进披露和角色表达。
- 全量输出每个 flow/skill 指标及 Pareto 候选。
- 只对高成本候选实施精简，并保存 before/after digest、指标和夹具结果。

## 验收标准

- [ ] 每个 flow/skill 均有 bytes、结构、重复和引用指标。
- [ ] 报告说明 bytes 是跨环境成本代理，不冒充模型真实 token。
- [ ] rubric 有定义、锚点和证据，不与自动指标合成总分。
- [ ] 每项接受的精简 UTF-8 bytes 降幅 >= 15%。
- [ ] 每项接受的精简通过全部既定确定性夹具，未覆盖场景已披露。

## 范围外

- 未达 15% 的微小精简。
- 以单模型主观评分作为科学基线。
- 未经配对验证的大规模重写。
