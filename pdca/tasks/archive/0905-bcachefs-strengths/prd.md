# bcachefs 内核设计优点与巧思分析

## 背景
用户要求分析 bcachefs 项目的各种优点与巧思。分诊定为 research 场景，范围限定内核设计（`fs/`，164 个 C 文件），视角为技术设计 + 工程实践双视角。

## 目标
产出 bcachefs 内核子系统优点与巧思的结构化分析，技术设计（数据结构/算法/正确性/性能权衡）与工程实践（错误码/可观测性/测试/构建）双视角，交付对话全文与 Markdown 报告文件。

## 功能需求
1. 覆盖内核主要子系统：btree、journal、alloc、EC、replicas、snapshots、recovery、sb、data 路径、compress、crypto、vfs
2. 每条优点/巧思给出代码位置引用（file:line）与机制说明
3. 工程实践视角：errcode 体系、recovery 可观测、自愈错误、测试桩等
4. 生成 Markdown 报告文件，并在对话中输出完整内容

## 非功能需求
- 只读分析，不修改 bcachefs-tools 任何文件
- 报告文件写入 PDCA 任务目录或 records，不污染外部仓库
- 结论须有代码佐证，不做无依据的泛化评价

## 验收标准
- [ ] AC-1 优点清单覆盖全部 12 个主要子系统且每条有代码位置引用
- [ ] AC-2 每条巧思均可按引用定位到代码实现，非空泛评价
- [ ] AC-3 报告文件存在且对话输出与文件内容一致

## 风险与对策
- 风险：164 文件全量深挖 token 不足。对策：按子系统分段并行深挖，每段抓代表性巧思而非穷举
- 风险：主观评价无依据。对策：每条必须 file:line 可定位，抽查复核
