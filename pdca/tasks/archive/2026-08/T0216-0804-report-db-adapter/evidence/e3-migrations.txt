T0216 Report DB Adapter — 迁移 up/down 双向实测

验证命令:
  cd /home/black/Downloads/report-center
  python3 -m pytest tests/test_migrations.py -q
  # test_migrate_up_writes_audit_and_creates_tables: up 后 8 张 dim_* 等表存在, 审计 SUCCESS/UP
  # test_migrate_idempotent: 二次 migrate 返回 False（已应用跳过）
  # test_down_rolls_back_tables: rollback 删除全部一期表 + 作废 UP/SUCCESS 记录, 再 up 恢复
  # test_rewritten_up_rejected: 记录 checksum 与当前文件一致
  # test_pair_present_for_all_versions: up/down 成对 + SHA-256

审计表设计（自裁决）:
  - down.sql 保留 rpt_schema_migration（rollback 后仍写 DOWN 审计）
  - rollback() 成功后 DELETE 对应 UP/SUCCESS 记录，保证重新 migrate 能重建表
  - applied_versions() 对不存在审计表返回空集（空库首次迁移）

命名统一: V001__init（§3.5.1），非 §3.5.5 的 0001_initial_report_schema（design.md 已裁决）
