# btreeGC专题学习

## 背景
新方式第 4 轮。btree GC 全流程学习报告 + 指南导航。

## 目标
产出 GC 学习报告（对话全文 + 文件）+ 新建指南导航节点。

## 功能需求
1. 精读 check.c GC 流程，讲透位点/水位/补标/拓扑/协同
2. 对话全文输出学习报告，并写报告文件，每节 file:line 锚点
3. 新建指南导航节点，聚合 GC 相关节点
4. 三查 + validate 全绿

## 非功能需求
- 只读分析；真实时间戳；主会话精读

## 验收标准
- [ ] AC-1 报告覆盖位点/水位/补标/拓扑且有代码锚点，每节有设计启示
- [ ] AC-2 报告文件存在且对话输出与文件一致
- [ ] AC-3 新建指南导航节点并过三查与validate，conclusion含##本体沉淀

## 风险与对策
- 风险：讲成流水账。对策：每节收束设计启示
