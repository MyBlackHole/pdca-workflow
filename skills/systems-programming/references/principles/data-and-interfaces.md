# 数据结构、缓冲与接口设计

设计或修改容器、索引、句柄、结构布局、字符串/二进制缓冲及回调接口时使用。所有权、预算和同步协议的详细规则仍由 [内存与锁](memory-and-locks.md) 维护；安全权限、路径和解释器边界由 [安全审查](../workflows/security-review.md) 维护。

## 从访问模式选择结构

先确认容量及增长方式、查找键、遍历/更新频率、顺序要求、稳定地址、共享关系与退出方式，再选择目标项目已有结构。

| 实际需要 | 优先比较的结构与代价 |
| --- | --- |
| 有限数量、顺序遍历或批处理 | 数组/连续存储；有界 FIFO 可比较环形缓冲。核对扩容、回绕、槽位复用及借用失效 |
| 已知节点的频繁插入/摘取或多种成员关系 | 链表/侵入式节点；核对局部性、每个节点的所属集合和父对象地址稳定性，不因内核常用就代替简单数组 |
| 按键精确查找 | 项目已有 hash/索引；核对碰撞、负载、扩容及最坏输入，不用链表线性查找掩盖容量要求 |
| 有序、范围或稀疏整数索引 | 树/相应索引；核对比较规则、范围边界、节点与被索引对象的不同生命周期 |
| 分配可复用编号 | ID 分配结构；编号不是对象引用，旧回调/请求与新对象的身份不能仅靠同一个整数区分 |

用户态选择允许的 C 接口或项目抽象，C 风格 C++ 不引入 C++ 库；Rust 采用目标环境支持的结构，不受 C++ 禁库规则影响。容器操作复杂度与缓存/内存收益有条件，性能结论另取证据。

## 容器与身份协议

- 插入、替换、摘取分别写清谁取得或放弃对象责任；容器结构安全不等于返回对象仍存活。查找至取得使用权的保护按 [生命周期](memory-and-locks.md#生命周期与退出协议)，不在取出悬空指针后补引用。
- 侵入式节点必须来自正确的真实父对象/成员且仍有效；同一节点不能同时属于两份独立链表，除非 API 明确支持。重新初始化、摘链和释放是不同操作；`container_of`、`list_del_init` 等不提供对象存活或并发保护。
- 内核 `list_for_each_entry_safe` 等先缓存下一项，支持特定的当前项删除；不保护其他 CPU 删除/释放当前或下一项，也不自动允许循环中解锁。按目标锁/RCU 协议处理，不能因名字含 safe 就去掉同步。
- 内核 XArray/IDR 等先按具体接口核对索引锁/RCU 及调用者的保护责任；即使索引访问受保护，也不自动取得所指对象的引用。普通与底层 API 的锁、分配上下文及返回编码不同；XArray 还区分值、标记及内部/错误项，按 `xa_err` 等实际接口判断，不把任意返回值当普通指针。
- 数组扩容、容器替换或环形槽复用会使旧地址/借用失效；需要稳定地址时采用适合的表示或另行保持对象。整数 ID、fd、槽位或地址复用还需可靠请求身份、代际校验或等待旧使用者收敛；代际回绕也在协议内。
- 迭代器、safe 遍历或容器快照的保证按 API 核对；并发视图是否一致、是否可能漏项/重项和重试副作用分别判断，不把逐项安全提升为事务快照。

## 数据表示与缓冲

- 明确字节序列、C 字符串和固定宽度文本字段的区别。二进制采用已验证的显式长度，不用 `strlen`；字符串须有可访问的终止符和容量依据。固定宽度协议字段可能需要填充且没有 NUL，不能机械替换复制函数改变格式。
- 格式串与参数类型匹配，不可信内容作为数据传入。`snprintf` 的非负返回值表示本应生成的长度；先处理错误和 `ret >= remaining` 的截断，再推进位置，不能直接累加为已写入量。内核 `scnprintf` 等返回实际存储量的接口也不能证明原输出未截断；选择依输出契约。
- 内核 `strscpy` 的负错误先保存在适当的有符号类型中判断，截断不是空字符串成功；它不负责检查任意无效指针、重叠或协议填充。用户态核对 libc/项目接口，不直接复制内核 helper。
- 长度、容量、有效字节及末尾 NUL 分别计量。零容量、精确容纳、截断、重叠、嵌入 NUL 和后续拼接要有定义；使用安全名字的函数也不能修复错误的容量。算术与窄化顺序见 [数据边界](engineering.md#数据边界安全与可移植性)。
- 数字/枚举解析核对完整输入、符号、进制、范围、尾随内容及失败值；按协议决定空白和换行规则。复用目标 `kstrto*`、`strto*` 等适合接口，不以成功解析一个前缀证明整段输入有效。
- 结构布局服务访问和兼容要求；内部可调布局与公开 ABI 分开。`packed`、位域、bool 或直接写出内存不能代替明确编码；若共享位域实际在同一存储单元更新，按真实冲突单位同步。

## 接口与回调边界

为真实变化点使用已有 ops/回调或小接口，不先为单个实现造通用框架。约定参数是借用还是消费、是否可阻塞/重入、同步返回与最终完成的区别、失败后的所有权及回调次数。

回调可能取得锁、重新提交、取消或释放参数；调用后是否还能访问对象由契约决定。回调函数表、上下文及必要模块/设备引用也必须有效。锁外执行的准备、对象存活及提交一致性按 [锁外操作](memory-and-locks.md#锁先减少共享再缩小临界区) 证明，不只移动一条调用语句。

公开接口维护行为兼容和能力发现；未支持操作、可选 NULL、错误与异步未完成分别定义。内核错误指针、用户态 errno/pthread 及 Rust Result 各按环境处理，不强行统一返回表示。

内核来源及适用条件见 [官方覆盖映射](../sources/official-docs.md)。
