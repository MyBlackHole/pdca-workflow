# Do：在原任务里实施获准计划

## 先定位，不以加载当授权

核对本文件经符号链接解析后的真实路径，定位集中 Git 工作副本 **PDCA_ROOT**。既有任务绑定优先于 cwd 或环境变量；与入口所在根冲突时停止，不在目标项目创建 `.pdca/` 或另一份 records。定位不等于批准业务操作。

先读[共同恢复入口](../../ontology/contracts/entry-recovery.md)，再读当前绑定项目 context、自己的 task/原 Agent 绑定、最后完整事件和当前请求。核对记录的 `rules_git_head`/`rules_git_status`；每次获准写入记录前按共同入口重新采集当前 Git 来源。已有任务不自动改绑或升级规则，原依据缺失或规则冲突时停止；不复制规则、不自动 checkout，不以新规则改写原授权。

当前会话不是该任务执行者时，只把真实用户操作路由回原 Agent 后停止本地执行；不可路由就阻断。**切换 Skill 不换 Agent**，不要调用新建工具、设置自动 fork 或由父 Agent 接管。加载方法、文件存在和上一阶段 PASS 都不授权本阶段。

开始前核对匹配 task/attempt/phase/run/subject 的原始用户回应、固定输入及撤权状态，并核验集中资源预约及实际写权。缺项时展示本阶段目标和缺项后等待；已有明确确认不要重复盘问。无任务时返回总入口定位，不在阶段 Skill 中新建。

## 当前 run 的动作

1. 确认 Plan 已完成、当前 Do 对象绑定其固定版本；返修必须有新的 Do run 和用户启动操作，不能覆盖旧失败证据。
2. 读取[Do 方法](../../ontology/process/flow-do.md)，按 task.scene 读取场景 Skill 的"阶段方法"。建模产出领域源与实例；投影产出实体和映射；验证场景实施只读核验和证据收集。
3. 取得并复核[集中预约](../../ontology/concept/resource-ownership.md)，固定实际对象与后端依据；按完整集合取得资源，未知结果先对账原 operation。不是在父 Agent 监控下逐步领取工作。
4. 在批准范围自主实现、调试和验证：保存失败复现，提出可反驳假设，做区分实验，修复后复验原路径和必需回归。目标、oracle、写域或不可逆动作变化先沟通。
5. 固定本 run 的模型/业务产物清单、映射、执行原始结果和缺项，集中保存，不把输出文字当真实产物。

## 任务分解执行

当 Plan 规定了子任务分解时，Do 按以下方式执行：

1. **薄切片执行**：每个子任务是贯穿所有相关维度（需求/模型/产物/测试/文档）的窄但完整路径，不是某个维度的水平切片
2. **阻塞边遵守**：子任务 B 依赖子任务 A 的产出时，B 必须等 A 完成后才开始
3. **前沿驱动**：所有阻塞项已完成的子任务组成当前可执行集，从中选择一个执行
4. **可验证交付**：每个子任务完成后应可独立验证——不要攒到全部做完才检查
5. **宽幅变更例外**：机械性全局变更（如重命名、格式统一）不强制薄切片，用"扩展-收缩"策略：先新旧并存，再分批迁移，最后删除旧形式

## 上下文卫生

- **共享上下文的步骤**：Plan→Do 衔接、同一 run 内的连续操作——这些步骤共享上下文，确保信息连贯
- **隔离上下文的步骤**：独立子任务、不同 run 之间——每个 run 应从固定输入重新开始，不依赖前一 run 的隐式上下文
- **压缩时机**：检测到推理质量下降（如重复已有结论、遗漏已知约束）时，主动 compact 并从固定输入重新加载

## 上下文生命周期

| 上下文类型 | 可丢弃条件 | 必须保留 |
|-----------|-----------|---------|
| Plan 固定版本 | 不可丢弃 | ✅ 整个 Do 阶段引用 |
| 前一 run 的执行结果 | 新 run 启动后可归档 | 保留摘要，不保留全文 |
| 调试中间产物 | 验证完成后可清理 | 保留最终结论和证据路径 |
| 用户决策记录 | 不可丢弃 | ✅ 所有 event 记录 |

**核心原则：** 代理不替用户做决定。事实收集归代理，决策归用户。Do 阶段在批准范围内自主实现，但目标、oracle 或写域变化时必须先沟通。

## 报告与停止

报告实际完成、失败和未验证范围，明确下一 Check 要核对的对象版本及标准。完成后等待 Check 授权，不顺手执行 Check/Act，不返回主 Agent 代做收尾。

**幂等性：** 同一 run 重复执行产生相同结果。新 run 必须有新的用户启动操作，不覆盖旧失败证据。
