# CASE-01：用例与oracle不由结果反推

每个case固定AC引用、输入、预期、可观察动作、失败条件和适用范围。正例证明允许行为，反例证明违规可被发现；纯规则文字扫描只称静态控制。

实际记录actual、命令／工具、退出状态、原始输出ref／摘要和对象版本。缺执行记not_run；基础设施失败记error／unknown，不冒充对象通过或不通过。模型置信度和多个Agent同意不是证据替代。
