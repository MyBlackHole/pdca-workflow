# 外部检索的条件与边界

是否需要网络由用户要求、事实时效和契约决定，不统一要求两个URL。内部代码任务可只依据获授权的源码。要求检索而宿主无能力时如实记录缺失；实际访问和引用相关性优先于链接计数。
