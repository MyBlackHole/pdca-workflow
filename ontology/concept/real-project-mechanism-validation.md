# 真实项目验证与模拟区分

机制验证在契约授权的真实项目环境运行，保存实际命令、版本、输出、退出状态和副作用。临时fixture可验证结构/边界，不等于真实多Agent执行；失败、未运行和不可用的能力如实报告。
