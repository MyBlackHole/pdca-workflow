# DECOMP-01：按独立交付拆分，不按操作拆分

候选孩子需有独立职责、输入输出、可独立拒收的成果和验证边界。创建文件、写方法、补测试常是一个节点内部步骤，不因操作数增加Agent。每个孩子由自己的Agent在Plan评估进一步拆分；父不替其评估或预设最终叶。

给出独立拒收见证、共享接口、组合责任和实际上下文负担；没有实质价值就保持leaf并在阶段内分批读取。不要以少Agent或少token为由合并已固定的独立义务。

分解产生候选seed及理由，向用户展示；用户选择后才由宿主创建。新孩子或新树版本不继承未来授权；所有正式节点各场景保持完整PDCA。
