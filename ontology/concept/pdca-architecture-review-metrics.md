# 架构审查的可证明指标

在契约要求架构审查时记录模块耦合、变更范围、测试覆盖和缺陷证据；指标来自实际读取/执行。可按需用宿主工具绘图或生成报告，不要求缺失的HTML生成器。内容和证据可复核优先于图表数量。
