## 四、新需求分析入口(路由流程)

```
需求
 → 判断子系统(01 fs-backup / 02 通道 / 03 公共库 / 04 介质 / 05 构建)
 → 按「二、需求类型」表选必读分册与章节，按行号 Read 指定段
 → 先过孤岛裁决(SKILL §4 + 01 §7 / 02 §7 / 03 §7 / 04 §6)：命中孤岛即停，换现行路径
 → 走任务链定位到函数级路径，每条过三项实证(存在/现行/逐字)
 → 涉通道即核对契约(01 §4 / 02 §4 / 04 §4)
 → 输出定位结论(文档依据 + 代码实证 + 复用判断 + 契约结果)
```
