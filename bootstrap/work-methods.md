# 当前阶段内按需使用的专业方法

方法不授权新阶段，不创建新Agent，不改变AC。先确认本任务目标、对象与输入；只选择适用方向。

| 方向 | 实际检查动作 | 需要保留的证据 |
|---|---|---|
| 问题／方案 | 区分事实假设；比较当前做法、约束、实质替代及重评条件 | 来源与目标、推荐理由及代价 |
| 状态／接口 | 从定义追踪读写、过滤、序列化、持久化、恢复及展示消费者 | 具体位置、遗漏与适用边界 |
| 并发 | 建立允许交错、终态和所有权；验证重复、取消、迟到、失败 | 可达路径／交错、资源释放与发布次数 |
| 存储／备份 | 对照原合同追踪写入、持久化、索引、恢复、重放和实际可恢复性 | 故障点、原始结果；静态检查不称恢复成功 |
| 性能 | 固定基线、环境、负载、单位及重复测量；先保正确性 | 原始测量、噪声和回归，不猜收益 |
| 安全 | 明确输入控制与权限边界，检查上游保护及反证 | 真实路径、限制，建议与已证缺陷分开 |
| 研究／知识 | 固定版本／来源，区分主张、证据与unknown | 定位及适用范围，不以链接存在代替正确 |
| 简化 | 删除无必要结构、重复平台能力和死配置，不删除真实错误处理 | 语义保持依据、回归；不凭行数裁剪功能 |

每次发现说明claim、支持、反证、verdict和关闭测试。专业性来自方法和证据，不来自角色名称或多Agent一致投票。
