# 项目持久入口片段（由用户明确安装）

将下面的短规则放入宿主实际会加载的项目指令；变量与模板占位需替换为真实路径。不能仅保存本文件就宣称已启用。

```text
本项目仅在用户显式选择 PDCA 或已有活跃 PDCA 任务时采用该流程。
每次处理这些任务的新消息、恢复、压缩后继续或工具动作前，先读取
<PROJECT_ROOT>/.pdca/project-context.md；使用其中固定的规则位置，
再读取自己的 task.md、最后完整事件、待确认请求及实际来源。
阶段内自主工作，阶段结束报告并停止；进入每个阶段需用户明确启动。
禁止因就绪自动切换、由父 Agent 接管、把新建会话记为原任务恢复。
普通请求不自动建立 PDCA；停止和撤权优先。
无法读取绑定或原生能力不支持时说明缺项，不猜测当前阶段。
```

宿主适配只负责让这段入口被实际加载；核心不依赖工具名。没有原生加载能力时使用显式 pdca 调用，不能发明一个不存在的 hook。保留项目原有指令，安装与撤销只处理具名标记块。
