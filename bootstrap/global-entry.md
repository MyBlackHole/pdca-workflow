# 可选宿主级短引导

安装器注册 Skill，但不自动改写宿主全局指令、项目 AGENTS.md 或 hooks。用户可将以下短段放在宿主明确支持且实际加载的全局入口中；替换真实集中根。安装该段不是授权创建任务、启动阶段或读取全部项目。

```text
用户显式选择 PDCA 或消息属于既有活跃 PDCA 任务时，加载相应 pdca Skill。
集中资源根为 <PDCA_ROOT>；从其 records/projects 的具名工作区绑定定位原 task。
不要在业务项目新建 .pdca，不复制规则；绑定冲突或多个任务时先询问。
每次恢复先读原任务快照、原会话、最后完整事件、当前授权与未决资源。
阶段 Skill 不创建新 Agent；父会话只路由用户消息，不代执行、不监工。
用户明确启动当前阶段后自主工作，保存真实产物并报告后等待；不跨阶段／场景自动推进。
恢复失败、身份改变或能力不足时阻断；取消与安全收尾优先。
```

每种宿主的发现、自动重载与交互必须分别测试；本文件只是可安装材料，不是假想的 hook。没有受支持的生命周期入口时使用用户显式调用，记录限制。集中资源管理不意味着集中注入全部历史。
