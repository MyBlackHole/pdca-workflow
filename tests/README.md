# 当前验证入口

```bash
python3 -m unittest discover -s tests -v
git diff --check
```

测试需要 Python 3.10+ 标准库、POSIX shell 与 Git，无 API 密钥，不启动宿主，也不修改真实用户目录。[安装器测试](test_install_script.py) 在临时用户目录运行实际 install.sh，使用可控 Git 替身记录调用和模拟克隆结果；它验证克隆参数、发现链接、已有目录/链接拒绝、缺 Git 拒绝，以及克隆失败仅清理本次新目录并保留相邻用户数据，不证明网络服务或真实远端克隆可用。

[文档与链接检查](test_skill_links.py) 覆盖当前维护入口、使用/安装文档、Skill 正文、本体权威/契约与测试说明的相对链接，以及已移除包层的路径缺席。设计记录、legacy 和未采用参考知识不作为当前控制链。

检查还覆盖九个入口名录、现行记录格式、Git 可跟踪/私有路径、显式绑定和只读辅助的关键边界，以及只读 Git 查询禁用可选索引写入。文本检查只证明定义存在，不证明 Agent 遵守；资源语义检查不是生产资源锁或仲裁实现。

[现场验收](host-acceptance.md)仍全部 `NOT_RUN`，包括真实宿主发现、绑定、原 Agent 恢复、阶段交互和辅助建议授权。不要累计旧验证包数字，或把静态检查与合成轨迹当作现场结果。
