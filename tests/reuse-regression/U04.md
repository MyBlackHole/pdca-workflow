# U04：同名不同单位或适用域不能直接复用

## 固定前置与被测对象

父要求单位为字节、无外部副作用；候选名字相似但可能以记录数计数，或者只适用另一产品版本。

模型中的LIB/D、DIGEST-*、FIX-*和授权标志仅为符号fixture；不是实际生产ID、摘要、用户消息或发布证据。宿主验收必须在授权沙箱绑定真实值。每个向量独立重置，不继承前一例状态。

## 执行动作

先核对接口单位/边界和固定source版本，再检查要求覆盖，不采用相似度作oracle。

## 正例、反例与oracle

正例：单位/范围匹配、事实已核验且必须义务覆盖才接受。

反例：单位错、适用域错、必需事实未知、父要求没映射。

逐字段比较model_vectors的固定expected；预期来自上述契约，在运行之前保存。正确拒绝错误资料是测试通过；测试器/环境坏了记error，不是有效拒绝。仅参考模型通过不能写host_result=PASS。

`NAME_SIMILARITY_IS_COMPATIBILITY`：故意省略 `fit` 检查，对 `wrong_unit` 运行原断言应出现差异。另跑全部正向控制，防止用“始终拒绝”取得假通过。变体未执行或构建失败是invalid，不计killed。
