# U20：已知错误阻断采用但不造成全局交付死锁

## 固定前置与被测对象

可信公告证明r1已采用约束错误；另一个节点的局部修复已完成而共享发布/其他树迁移仍在等待。

模型中的LIB/D、DIGEST-*、FIX-*和授权标志仅为符号fixture；不是实际生产ID、摘要、用户消息或发布证据。宿主验收必须在授权沙箱绑定真实值。每个向量独立重置，不继承前一例状态。

## 执行动作

保留r1字节和历史失败，阻断相关危险继续使用；分别评价当前节点局部交付、共享发布与全局issue。

## 正例、反例与oracle

正例：受影响旧采用block_and_rework；本地要求已独立证明、全suite和完整PDCA完成时可先交付，global issue保持开放。

反例：因为版本固定忽略已知错误；本地无证据却以candidate_only放行；要求等待所有树完成才交付孩子。

逐字段比较model_vectors的固定expected；预期来自上述契约，在运行之前保存。正确拒绝错误资料是测试通过；测试器/环境坏了记error，不是有效拒绝。仅参考模型通过不能写host_result=PASS。

## 错误实现／错误规则控制

`CHILD_WAIT_FOR_GLOBAL_PUBLICATION`：故意省略 `global_wait` 检查，对 `local_ready` 运行原断言应出现差异。另跑全部正向控制，防止用“始终拒绝”取得假通过。变体未执行或构建失败是invalid，不计killed。

## 必须观测与证据

真实advisory/控制顺序、采用约束匹配、本地及祖先/跨树回归分层、原失败字节。

分别保存规则/数据版本、原始输入、expected/actual、断言位置、真实动作、环境、清理及局限。真实身份和授权不能由本案例自己生成；示例有意错误只能在隔离副本注入。

## 失败定位、修复与回归

按受影响范围安全停止→对应节点新attempt/新Agent或新树→孩子本地先交付→祖先组合/独立审查→逐工作关闭，global缺口不得抹去。

先保留原失败→最小复现→固定回归案例→可证伪修复→本例全部正反例和错误控制→当前节点全部必需suite→实际影响的组合/采用者回归→独立复审。不得改expected或删除反例换PASS；Do内同合同预算允许有限修复，Check后/合同变化新attempt、新Agent。跨树全局关闭不能反向阻塞本地合格任务。
