# U06：更严格输入不等于可替换原接口

## 固定前置与被测对象

有限教学输入域{0,1,2,3}是base合法域；local可能缩成{0,2}，或者删除pure保证。

模型中的LIB/D、DIGEST-*、FIX-*和授权标志仅为符号fixture；不是实际生产ID、摘要、用户消息或发布证据。宿主验收必须在授权沙箱绑定真实值。每个向量独立重置，不继承前一例状态。

## 执行动作

分别比较前置输入域与输出保证。局部内部加强可保持接口；缩域须承认新契约而非完全可替换。

## 正例、反例与oracle

正例：保持原合法域和保证可通过；显式new_contract且获新的局部需求和测试可以限定作用域。

反例：局部忽略base的pure；缩窄输入却声称substitutable。

逐字段比较model_vectors的固定expected；预期来自上述契约，在运行之前保存。正确拒绝错误资料是测试通过；测试器/环境坏了记error，不是有效拒绝。仅参考模型通过不能写host_result=PASS。

## 错误实现／错误规则控制

`STRONGER_PRECONDITION_IS_ALWAYS_SUBTYPE`：故意省略 `substitutability` 检查，对 `narrow` 运行原断言应出现差异。另跑全部正向控制，防止用“始终拒绝”取得假通过。变体未执行或构建失败是invalid，不计killed。

旧新输入集合、保证集合、compatibility声明、适配边界以及两侧边界样本。此有限域模型不证明任意程序子类型。
