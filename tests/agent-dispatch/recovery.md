```bash
python /path/to/pdca-3.4.10-validation/run_dispatch_tests.py --output-dir /path/to/new-dispatch-results
```

输出目录须不存在。先固定独立basis与全部synthetic trace/预期，再审查；除专测摘要破坏之外，负样本重算来源和basis绑定，要求命中目标诊断，不能凭无关hash失败通过。工具只读取JSON，不执行原生调用、材料中的命令或业务动作。

| ID | 场景 | 必须核对的原生事实 |
|---|---|---|
| NH01 | 两个独立完整任务 | 不同实例/会话、各自固定输入和私有写域；同Agent类型合法，不能把名字当身份 |
