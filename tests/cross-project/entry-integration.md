# 跨项目入口交接回归 · entry-hotfix.1

本页的有限回归验证真实分发包的读取路径和文件内容，不声称执行 AI 语义、全局指令自动加载或正式 PDCA。基础双根 v2 语义不变，原104项检查应继续运行。

| 范围 | 错误输入 | 合法控制 |
|---|---|---|
| 真实读链 | 缺 ontology/README、缺 phase入口、读集缺关键角色、读集跳到目标 | 原主包全部显式读集能从外部 cwd 读取 |
| 启用 | 已加载全局规则却要求每次重复说 PDCA | 非空变量启用；变量空且未选择不强制普通项目 |
| 根 | 错变量静默回退、嵌套、别名冒充隔离 | 绝对/相对PDCA_ROOT、同根、路径空格、目标子目录 |
| 文件与版本 | 改了规则未更新摘要、清单缺必读项、关键ID被交换路径 | 明确读集与实际发布字节对应；release不自引用 |
| 权限 | 文件不可读、records不存在却自动mkdir、records符号链接 | 只读模式不创建；显式探测使用唯一新文件并清理 |
| 输出边界 | probe通过宣称Agent已加载/已批准/已独立执行 | 这些状态保持not_verified/NOT_RUN |
| 内容保留 | 诊断改源码、覆盖已有probe文件、保存全部环境 | 默认无文件改动；原dirty/untracked及env其它项不输出 |

文档触发条件的静态断言不是对自然语言 Agent 的行为测试。显式用户“本次不用PDCA”和父派发/恢复优先固定上下文属于已写入规则的语义条件，实际宿主行为待测试。不得以程序按读表打开文件证明Agent按指令打开文件。
