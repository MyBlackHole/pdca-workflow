# 语义开发集：不把结构通过当成语义通过

12个公开开发样例分别覆盖真实冲突/前提差异、否定/引用/真实声称、目标共同缩水、数据中注入指令、正文与frontmatter冲突、旧证据和缺来源的unknown。

subject与oracle物理分离。向被评检查器只传固定任务说明、通用规则和subject字节；oracle、cases包装及答案映射只在外部评估侧读取。被评上下文必须保留实际清单和摘要；如果整个仓库已暴露给检查器，不得声称它没看到答案。

当前全部是公开开发集，作者已见过，不声称保留集或盲测。正式保留集应由独立评估者在检查方法冻结后新制，单独存放；修改测试集后重新标版本和暴露历史。v3.4.2创建这些固定材料时没有实际语义run；不能用空数组统计成0%漏报。

实际评估分别记录漏报、误报、unknown、证据定位和越权行为。字段/字节检查只验证输入隔离及oracle定位，不判任意文本语义。SD09对应上一轮P13：仍需真实独立语义判断，未写一个匹配此句的正则来冒充解决。

本轮新增的当前会话公开开发评估见[结果](../../examples/formal-records/semantic-development/README.md)；冻结suite/case不回填运行结果。该运行不是保留集、独立Agent或正式PDCA；评分映射的事后固定和首轮证据缺失均保留。
