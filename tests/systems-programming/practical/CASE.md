# 业务请求：可借用版本缓存

实现 Linux 用户态 C 模块，用于多线程采集服务。公开接口固定为 vstore.h。新增代码为 C；头文件须可被 C 风格 C++ 调用，不使用 C++ 库，不增加第三方依赖。

生产者按 uint64_t key 发布二进制快照。发布成功后可立即复用输入缓冲；获取返回该 key 在某一时刻最新的快照视图。同一 key 后续被替换，先前已经获取的视图仍应保持原内容，直到归还。视图可交给另一线程归还；每个成功获取的视图恰好归还一次，归还后的视图清零。

服务长期运行，多个发布者/读取者可并发调用。配置限制同时保留的快照版本数及其 payload 总量；单条数据可能很大，也可能长度为零。正常负载可为四发布者、四读取者，配置示例为 64 个版本、64 KiB payload。条数/字节不足不等待容量，返回 -EAGAIN；单条超过配置返回 -EMSGSIZE。零长度允许 NULL，仍是一份快照。

内部接口采用负 errno。分配失败返回 -ENOMEM 且之后仍可正常使用；其他无效参数为 -EINVAL。获取不存在 key 为 -ENOENT，失败时输出视图清零。create 失败时 out 为 NULL，配置上限不可为零。stats 可并发读取完整快照，当前与峰值不得超过配置。

close 立即停止新的发布和获取，合法调用返回 -ESHUTDOWN；已获取视图仍可读取和归还。重复 close 成功。destroy 隐含关闭；若还有视图未归还则返回 -EBUSY 并保留可归还/再次 destroy 的句柄，归还完成后 destroy 成功。destroy 调用方负责排除其他公开 API 的同时调用；不支持已销毁句柄的访问。不要加入未要求的持久化、后台回收线程或网络功能。
