# 当前入口与发布一致性：有限维护回归

本套件定义维护检查范围，不是新业务门禁或真实宿主行为测试。代码在配套验证包，policy 从原3.4.7已审成员集合及本轮明确新增路径固定，不从被审候选清单反推。

| 分组 | 原反例／变体 | 合法控制 |
|---|---|---|
| 当前版本 | 模板说明、扩展 protocol_revision、当前验证链接陈旧 | 旧 schema 与旧历史说明继续合法 |
| 单源投影 | 改 release 后遗漏当前入口、shape 摘要、索引或成员摘要 | refresh 后重复执行不再产生变化 |
| 成员与角色 | 删除旧必需成员、加入未登记运行入口、把参考知识改为规范权威 | 明确增加的支持文件被纳入清单 |
| 读取／动作导航 | 丢必读文件、丢角色行、缺阶段或恢复链接 | 原必读集合与28项权威保持；这是导航检查，不认证语义等价 |
| 知识修复 | 丢对照 commit、丢未验证边界、重新放回已撤回错误状态标识 | 原 ID 保留，采用仍需 claim-review |
| 历史完整性 | 篡改 records、示例或旧迁移文本 | 原文件逐字节不变，新版说明另建 |
| 输入／输出安全 | 重复 YAML 键、路径越界、符号链接、policy 在候选内、输出已存在 | 根外新输出；失败保留非零退出和具体诊断 |

原静态审计继续覆盖 YAML、ID、ontology 引用、关系环、Markdown 文件链接、release 与 shape 摘要。本轮新增反例不能被解释为原68个行为案例已经运行；真实宿主和效果 A/B 保持未运行。
