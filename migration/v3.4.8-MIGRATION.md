# 3.4.8 采用与接续

解压新源码包到独立目录，先查看当前验证说明。新工作明确采用新 protocol-release；已有活动任务继续使用固定原快照。不要将新版模板、根路径或确认摘要覆盖旧 records；需要迁移时按原 ADOPT/REWORK 生成接续事实。

protocol_revision 是当前发行投影，extension_revision 是扩展语义版本，schema 是记录模式，资产 revision 是自身内容版本。本轮不批量升级 schema，不按当前发行号否定旧冻结记录。

标准技能目录名为 pdca，必须连同相对依赖安装／发现；不要只拷贝 SKILL.md。继续使用全局规则的宿主需显式更新过去复制的正文；本次不自动编辑任何用户宿主配置。不配置 adapter，不新增宿主特定 API。

完整分发包包含源码包与独立验证包，并用外层 MANIFEST.json 固定二者摘要，避免主清单与验证结果相互包含产生哈希环。验证包内含原始3.4.7输入、policy、脚本和原始输出；不能用过去聊天里无法取得的附件顶替。

只更新当前导航，历史报告、fixtures和真实records均保留原字节。本轮源树补丁应在原输入的副本应用，不自动替换活动部署。未取得真实宿主能力与阶段轨迹时仍不得宣称正式运行通过。
