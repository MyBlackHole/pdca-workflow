# v3.4.3 迁移

主补丁相对v3.4.2工作流根目录；验证补丁相对v3.4.2-validation根目录。两者分开应用。先git apply --check，再git apply；不要把验证代码放入主协议。已有本地变更时手工解决冲突，不跳过失败块。

既有task/record的schema仍按原版本，新的固定记录声明protocol_revision=3.4.3。不要把旧记录中的3.4.2全局替换为3.4.3，更不要重算历史批准对象让旧确认适配新对象。旧运行继续用其固定协议，下一attempt按新协议重新建立真实基线和授权。

CONTRACT的fixed_record_shapes移至record_shape_index_ref/digest。工具通过索引选择record_kind并核对其摘要及template_digest；未知profile返回incomplete。当前模板中的空字段是草稿，completed-only维护profile不得强加给合法中止记录。

单叶示例为本版本的合成维护样例，其身份补充与摘要链重算不构成真实执行。历史116份记录未修改。真实试点沿用既有live-pilot，不以本次“优化仓库”指令替代未来各阶段确认。
