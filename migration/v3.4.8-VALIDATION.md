# 3.4.8 验证范围与复跑入口

本版本配套文件为 `pdca-3.4.8-source.tar.gz`、`pdca-3.4.8-validation.zip`；完整分发包 `pdca-3.4.8-bundle.zip` 包含两者与外层 MANIFEST.json。该外层清单固定字节完整性，不认证用户授权或发布资格；缺任一必需附件即验证材料不完整。

验证包 README 给出依赖、原始输入摘要和直接可执行的复跑命令。包括：原静态审计；当前版本／必读集合／规则注册表／成员角色／索引与模板摘要检查；原历史字节比较；有限合成反例；投影刷新幂等性；新输出与错误诊断控制。所有结果、命令、退出状态保存于验证包 results，具体计数以逐项输出为准。

新增检查器在候选源码树外使用独立 policy，不能自动用候选自述减少必需成员。源码包仍只有 Markdown 与 .gitignore；验证脚本不是运行器、adapter 或业务授权入口。

ZFS修复来自固定OpenZFS commit的函数级人工源码比对，来源记录在配套 sources/source-review.md；回归只防止已知表达与元数据退化，不是任意 C 语义验证或 OpenZFS 运行测试。其原研究源码版本未确定，维持 reference / unverified。

**本轮未运行**：原68个宿主行为案例、真实新Agent／恢复／确认消费／写权并发试点、原业务测试、真实输入token或效果A/B。之前3.4.7文档提及但本次上传不含的独立维护代码也未复跑。新版本、正确摘要或新维护PASS均不自动关闭这些未证明项。

[当前维护套件](../tests/entry-maintenance/suite.md)定义有限关系和合法控制；[历史3.4.7说明](v3.4.7-VALIDATION.md)仅解释旧版本。

本次原输入没有 `records/` 目录。历史完整性逐字节核对的对象是包内原 examples、固定 tests 资料（不含当前 tests/README 导航）及旧 migration 文件；不称为真实 records 重放。
