## 已实施范围

本版是Markdown协议与模板的文件修改，不是已运行的多Agent系统。修正上一版的三项偏离：工作目标固定组成树；每个场景每个目标节点（根/内部/叶）完整PDCA；取消Do→Check父Agent审查批准。独立审查成为第三场景的节点任务。

新增8个本体节点：工作树、节点契约、三场景、树形调度、任务单元测试、案例模式、返工、独立审查。原有569个ID全部保留，总577。根规则索引20项；运行模板18种。知识资产仍用pdca.asset/v2；本次修改的节点revision=3.0.0，未涉及的领域资料保留原版本，运行实例/模板模式为v3。

测试和返工按一个节点的一次场景任务设计：固定suite/case/oracle；正例、非法输入、边界、故障/组合和错误变体；真实run、有限修复预算、失败复现、同版本全必需回归、受影响祖先失效和独立复审。详细示例含36条逐文件案例、9个错误实现变体、5类返工演练；另有七节点三场景教学模型。

## 不兼容语义

| v2 | v3 | 迁移要求 |
|---|---|---|
| 有界子图可投影树/DAG，不强制每节点任务 | 工作目标固定唯一父归属组成树；上下文选择不改变任务数 | 先确定work/tree/node，再逐场景建立任务覆盖 |
| ontology_role字段 | scene为唯一场景字段，使用原三种职责取值 | 不双写；已有事实/授权不得直接重命名就声称有效 |
| 没有work/tree/node/attempt身份 | pdca.task/v3明确这些身份及新旧尝试链 | 无法可靠映射的旧任务保持原协议，不猜关联 |
| Do等待协调器审查 | 任务自检后自行Check，独立审查单独新Agent | 旧审查回执不能冒充第三场景完整任务 |
| parent不区分目标归属 | parent_node_id表示组成，不是父Agent控制关系 | 删除隐含阶段控制与跨任务代签 |
| 泛化正反例/测试摘要 | 逐约束suite/case/run/artifact、actual/expected与oracle | 没实际运行的写not_run，不能补造日志 |
| 返工只记录建议 | Do内有限修复；Check后新attempt新Agent | 失败不覆写，最终版本完整必需回归 |
| 新产物沿用旧组合PASS | 实际依赖与祖先组合/审查标stale | 新发布必须对应新的真实固定输入 |
| awaiting_review | 不再有等待父放行的状态 | 真正用户等待用awaiting_confirmation/input；无法恢复标interrupted |

## 升级操作

解压到新目录。新工作从[AI入口](../ontology/README.md)开始，由宿主验证隔离、自主运行、独立消息路由与调度/测试能力；缺能力保持未执行。

已有v2任务继续引用原冻结规则和证据，不能在运行中就地替换验收。需要接续时确认旧写权撤销和未知副作用，创建v3对应节点新attempt及全新Agent；旧任务、确认与失败历史保留。原包没有提供实际工作任务，本次未迁移生产实例或补造真实确认。

[模板](../templates/README.md)仅草稿；[案例与返工](../examples/range-task/README.md)仅教学；[宿主验收](../tests/behavior-cases.md)68例均未在真实宿主执行。[验证报告](VALIDATION.md)列出实际静态与参考模型检查；完整差异见随交付patch。

## 保留边界

不捆绑Python/Shell运行代码、adapter、守护程序或自动CI。维护时使用的外部检查程序不进入项目，不是新的运行依赖。宿主需真正实现隔离、写权和路由，Markdown不是锁/签名/事务。

未重新核验继承的bcachefs/ZFS/加密等技术资料；本次修的是工作协议，不把历史源码行号或产品主张重新认证为真实。七节点教学中除B1详细套件外，其他节点用于结构/组合示意，真实使用前必须按模板补全各自suite，不能假装已有生产实现。
