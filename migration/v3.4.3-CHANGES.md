# v3.4.3 修改范围

本版针对上一轮N01—N12修复有限的正式记录关系检查，保持三场景、每节点完整PDCA、新Agent、递归和父局部交付边界。主包仍为Markdown；代码在独立维护附件。

门禁核对当前对象、嵌套权威及证据；观测核对task/attempt/run和case/产物/检查器/可见输入；证据集合核对成员覆盖；树规格与工作节点、清单角色、图及外部basis交叉核对；约束映射检查两端。

20类字段投影从CONTRACT frontmatter移动至按需索引，绑定原模板。记录schema不机械升级。正式示例仍为fixture，仅补充当前维护绑定和摘要闭包，不倒填历史records。

维护输出增加执行断言及覆盖：字段/关系子集可以pass，整体PDCA仍incomplete；真实语义、宿主确认、Agent隔离、写权及发布均未运行。停止/失败完整记录profile尚未实现，明确unsupported，不伪造已完成链。
