# cross-project.2：单变量入口

基于3.4.4 + cross-project.1；协议主版本不变。用户只需可选PDCA_ROOT，目标=初次真实cwd，未设/空值则两根相同。新增通用全局入口提示，不自动安装到宿主；没有入口加载事实不声称自动启用。

契约、binding、context升级为v2；支持shared和split，严格嵌套仍拒绝。工作树子目录保留真实开发范围，不自动扩大到git根。project/workspace按精确旧身份复用或内部生成。后续cd、新Agent和恢复沿用固定上下文。

历史v1记录/测试仍按原契约；不就地改版本或摘要。迁移需保留旧契约快照再形成新绑定。旧TARGET_ROOT环境不作为v2入口输入；本轮既不读写用户真实目标仓库，也不安装全局Agent配置。

主包保持纯Markdown，维护代码独立交付。发布清单为当前分发快照，不认证正式宿主批准。
