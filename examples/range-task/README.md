# 一个任务的详细单元测试与返工

教学对象是七节点工作树中的B1范围校验实体，参见[节点合同](node.md)、[39例套件](suite.md)、[13个错误实现变体](mutations.md)、[返工过程](rework-walkthrough.md)。所有文件明确标记example_only/NOT_RUN，不是用户任务实际完成证据。

每个案例是独立Markdown文件，包含精确输入、规则ID、预期返回和错误优先级、禁止副作用、oracle、实际观测、失败区分与清理。案例继承已固定合同，不靠父Agent对话补信息。

正例代表合法边界与典型行为；反例包含错误类型、布尔冒充整数、缺参数、负值、空长度、容量/区间边界和u64溢出。非法输入正确拒绝应为PASS；错误实现变体必须被原案例识别，而不是靠编译失败算击杀。

真实任务在Plan绑定具体语言/工具入口，Do实际执行，失败按REWORK-01处理；本教学数值模型不保证任何真实存储系统正确，也不包含运行时Python。
