# B2：原子应用

## 目标与组合

在已验证合法范围内先生成新块，再一次提交；教学内存模型发生before_commit注入失败时保持原块，返回E_APPLY。真实持久化不在本例范围。

叶子；合法范围是前置，不负责再次定义B1范围规则；调用者不得传非法范围。

必须AC：输入/输出及错误语义符合上述合同；授权范围内无额外副作用。此示例只说明任务边界，真实冻结前仍需填NODE-01完整接口与suite，不可把本教学片段直接当生产完整基线。

## 执行测试具体样本

正例输入：state=00×16,offset=1,data=[1,2],fault=none。预期：OK；state=00 01 02 00×13。

反例输入：同合法输入，fault=before_commit。预期：E_APPLY；原16字节状态不变，无部分覆盖。

判定：固定初始对象，调用当前节点，精确比较返回/输出/前后状态；组合节点追踪真实孩子调用及版本；异常、环境错误或缺日志不能当PASS。测试后先固定证据再清理沙箱。
